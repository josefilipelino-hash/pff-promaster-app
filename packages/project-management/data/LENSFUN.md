# Perfis de objetiva — origem e licença

`lensfun.json` é uma conversão (com `scripts/lensfun_to_json.py`) da base de dados de
objetivas do projeto **Lensfun** (https://lensfun.github.io, repositório
https://github.com/lensfun/lensfun, `data/db`, versão indicada no campo `source` do JSON).

A base de dados da Lensfun é © dos seus contribuidores e está licenciada sob
**Creative Commons Attribution-Share Alike 3.0** (CC BY-SA 3.0) — texto completo em
`COPYING.CC_BY-SA_3.0`. Esta conversão é distribuída sob a mesma licença.

Alterações feitas na conversão: só os campos usados (câmaras, encaixes, distorção, TCA e
vinheta); formato JSON compacto. Nenhum valor de calibração foi alterado.
